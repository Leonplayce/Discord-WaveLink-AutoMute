# Security Policy

[English](#english) · [Deutsch](#deutsch)

## English

### Supported versions

Security fixes are provided for the latest release and the current `main` branch.

### Reporting a vulnerability

Please **do not open a public issue** for security problems.

Use GitHub's private vulnerability reporting:

1. Open the **Security** tab of this repository.
2. Click **Report a vulnerability**.
3. Include the affected version, steps to reproduce, and the impact.

If private reporting is not available, open a minimal issue asking for a private contact channel — without technical details.

### Scope

This is a local Windows tool. Relevant reports include, for example:

- command or path injection through user-controlled values
- unsafe file or registry permissions
- privilege escalation
- arbitrary code execution through configuration or update mechanisms
- unintended network access or data collection

Out of scope: SmartScreen or antivirus warnings, the manual confirmation during installation, attacks that require physical access, and social engineering.

### What to expect

This is a volunteer project without a bug bounty. Reports are handled on a best-effort basis. Please allow time for a fix before public disclosure.

## Deutsch

### Unterstützte Versionen

Sicherheitsfixes gibt es für das neueste Release und den aktuellen `main`-Branch.

### Sicherheitslücke melden

Bitte **kein öffentliches Issue** für Sicherheitsprobleme erstellen.

Nutze GitHubs vertrauliche Meldung:

1. Öffne den Tab **Security** dieses Repositories.
2. Klicke auf **Report a vulnerability**.
3. Nenne die betroffene Version, Schritte zum Nachvollziehen und die Auswirkung.

Falls die vertrauliche Meldung nicht verfügbar ist, erstelle ein minimales Issue und frage nach einem vertraulichen Kontaktweg — ohne technische Details.

### Umfang

Dies ist ein lokales Windows-Tool. Relevant sind zum Beispiel:

- Kommando- oder Pfad-Injection über benutzergesteuerte Werte
- unsichere Datei- oder Registry-Berechtigungen
- Rechteausweitung
- Ausführen von beliebigem Code über Konfigurations- oder Update-Mechanismen
- ungewollter Netzwerkzugriff oder Datensammlung

Nicht relevant: SmartScreen- oder Antivirus-Warnungen, die manuelle Bestätigung bei der Installation, Angriffe mit physischem Zugriff und Social Engineering.

### Erwartung

Dies ist ein Freiwilligenprojekt ohne Bug-Bounty. Meldungen werden nach bestem Bemühen bearbeitet. Bitte gib Zeit für eine Korrektur, bevor du Details öffentlich machst.
